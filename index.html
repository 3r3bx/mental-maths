🔔 Streak reminders

Once a day at 5:00 pm, this iPad gets a reminder. If today's round isn't done yet, it warns that the streak is at risk. If it is done, it says the streak is safe.

Last step: send this reminder code to Claude, or save it in the GitHub repository as the secret PUSH_SUBSCRIPTIONS.

Needs iPadOS 16.4 or later, with the app opened from its Home Screen icon.

💾 Back up progress

Progress is stored only on this iPad, and Safari can occasionally clear it. Save a backup now and then, for example to Files or iCloud Drive. You can also use a backup to move progress to a new iPad.
