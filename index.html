👥 Players

Each player has their own progress, avatar, streak and settings. With two or more players, the app asks "Who's playing?" when it opens.

🔔 Streak reminders

Once a day at 5:00 pm, this iPad gets a reminder. If today's round isn't done yet, it warns that the streak is at risk. If it is done, it says the streak is safe.

Last step: send this reminder code to Claude, or save it in the GitHub repository as the secret PUSH_SUBSCRIPTIONS.

Needs iPadOS 16.4 or later, with the app opened from its Home Screen icon.

🎚️ Practice and difficulty

Locking keeps practice on one table or topic, for example before a school test. Focus mode and the check-up aren't affected.

Topics and difficulty

Untick a topic to leave it out everywhere, including warm-ups and reviews. A mode with nothing left disappears from the home screen. One of adding, taking away, times tables and dividing always stays on.

Each difficulty moves by itself. It goes up after 10 recent answers at 85% or more right, and down if the last 8 fall below 60%. Use − and + to nudge it. These are for whoever is selected above.

⏱️ Round length

Best scores and the ghost are kept separately for each length, so a longer round never beats a shorter one unfairly. Check-ups are compared as % right.

💾 Back up progress

Progress is stored only on this iPad, and Safari can occasionally clear it. Save a backup now and then, for example to Files or iCloud Drive. You can also use a backup to move progress to a new iPad.
